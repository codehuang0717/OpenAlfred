# 摘要生成预算拆分与复测

## 状态

2026-09-27：完成预算解耦、错误诊断和回归测试。增量摘要真实复测通过，但压力场景仍失败；**尚未完成稳定性验收，不应标记为完全修复**。

## 已修改

- `CONTEXT_SUMMARY_TOKENS=1600`：最终落库摘要的本地 token 上限，未放宽。
- `CONTEXT_SUMMARY_GENERATION_TOKENS=4096`：独立 API 生成额度，通过请求体校验确认发送。供应商输出计数与最终 JSON 的本地计数不是同一口径。
- 摘要总请求预算维持 `CONTEXT_SUMMARY_INPUT_TOKENS=12000`。分批时同时预留旧摘要、生成额度、schema、提示和安全余量；更多生成空间意味着更小证据批次，可能增加调用次数。
- 长度截断和 60 秒超时转换为带明确原因的本地错误，保留异常链。失败不提交半成品，不调用备用模型，不自动重试。
- 严格模型工厂不仅更新 LangChain 字段，也关闭已初始化 OpenAI-compatible SDK 客户端的重试。单独修改 `model.max_retries` 不会更新其现有客户端，这一点已用模拟 HTTP 500 验证只发送一次。
- 探针补充底层异常类型与本地错误说明，不记录供应商错误正文、密钥或请求头。

## 本轮真实调用

同一个已配置 MiMo 模型，全部为合成材料。共尝试 6 次 API 请求；没有读取个人记忆、执行工具或操作真实账号数据。

### 增量摘要回放：4 次请求，成功

复现之前两步增量摘要的历史结构，模型输出非确定性，不声称逐字重放相同请求。

| 阶段 | API 输入 | API 输出 | 最终摘要本地 token | 调用耗时 |
| --- | ---: | ---: | ---: | ---: |
| 摘要 1 | 581 | 1478 | 157 | 20.0 秒 |
| 摘要 2 | 468 | 2750 | 168 | 30.7 秒 |

随后两次主回答均为正确的 `SHORT-427`。生成额度扩大后，没有再把第二步截断在 1600，但仍有明显摘要等待时间；不能把这一结果描述为延迟已改善。

### 压力场景：2 次请求，未通过

使用生产规划器、12000 主上下文测试预算主动触发压缩。第一批摘要成功：输入 3479、输出 1018、耗时 26.75 秒。第二批返回 `ContextBudgetError`，主模型没有被调用，测试停止。

该次运行只记录了外层类型，没有保留异常链，不能据此断言是再次长度截断或 60 秒超时。第二次调用的 token 用量未知，不记为 0。新增诊断代码尚未用于又一轮付费复测，避免在根因不清楚时反复增加调用或扩大预算。
