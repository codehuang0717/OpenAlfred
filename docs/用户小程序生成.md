# 用户小程序与 Coding subagent

## 使用方式

重启后端 API、LangGraph 与前端，确认已运行 `uv sync`。聊天选择模型后，可输入：

> 用 Coding Agent 根据我的待办和最近 10 封邮件，编写一个校招投递与测评时间线小程序。显示开始和截止时间，支持筛选；不要修改我的原始数据。

主 Agent 提交任务后即可回复，不等待整份代码。聊天任务卡显示排队、编码、验证、修复及完成报告；切换会话不停止任务。右侧工具箱中先运行草稿预览，确认后手动发布。生成失败不覆盖已发布版本，不自动切换模型。

## 私人数据与权限

Coding Agent 独立使用本人待办、邮件账号/邮件、画像/分类记忆、知识库列表/搜索等只读工具。用户身份和时区由后端绑定，模型不能指定其他用户。不会继承修改/删除数据、发送邮件、电话、本机文件访问或 shell。邮件读取必须指定具体账号，不能回退到账号列表第一项。

按需读取的数据是生成时快照：所需字段可以写进小程序源码，用户可查看代码；不是匿名数据。程序不获得 JWT、密码或动态账号 API，也不会自动同步。需要实时待办更新时，继续使用受信任的标准待办时间线组件。

长数据结果保存在任务 checkpoint 的只读逻辑文件中；编码模型收到短预览，可用 `read_file` 按行/字符分页读取。不会把完整私人结果与源码传回主聊天。删除小程序会清除修订、任务、事件及所有重试代次的 checkpoint；删除途中崩溃时，下次 API 启动清理孤儿 checkpoint。

## 编码与任务生命周期

使用 LangChain `create_agent()` 与 LangGraph checkpoint。逻辑工作区仅包含 `index.html`（body 片段）、`styles.css`、`app.js`，支持读取、写入、hash 校验的局部补丁和验证反馈修复。源码修改使旧验证失效；必须对当前源码通过 `validate_app` 并调用 `finish_task` 才能交付草稿。空输出、截断、非法工具、API 失败或仅口头说完成均不能成功交付。

任务和事件保存在 `todos.db` 的用户应用表；独立 checkpoint 默认位于 `data/coding-checkpoints.sqlite`，禁止提交。FastAPI 管理有界异步 worker 池，不为每个任务创建 Python 进程。事务领取、45 秒租约、2 秒 heartbeat 与执行代次防止重复领取和取消后的过期完成。

状态为 `queued/generating/ready/failed/cancelled/interrupted`。可取消、恢复检查点或重新生成；服务中断不会偷偷重新请求模型。恢复累计原预算，无有效 checkpoint 时明确失败；重新生成使用新检查点和预算。前端每 1.5 秒补读聊天任务事件，刷新可恢复报告，终态停止轮询；API 另提供 SSE。

## 配置与验证范围

`.env.example` 中的 `CODING_*` 默认并发为全局 2 / 每用户 1，模型调用 24 次、修复 3 次、输出 16,000 token、总时长 900 秒。应用输入/累计 token 限制默认关闭（`CODING_INPUT_TOKENS=0`、`CODING_TOTAL_TOKENS=0`），设为正数可启用；供应商本身的上下文和输出限制仍有效。估算统计使用 `cl100k_base` 计算协议消息、推理字段与完整工具 schema，不再把 UTF-8 字节当 token；非 OpenAI 供应商并非精确计数。实际 usage 单独记录，无指标则为不可用。

旧版本被新版安全规则拦截时，面板显示具体接口或格式错误，原始源码仍可查看。点击“生成兼容草稿”显式启动原模型修订，将 HTML 字符串注入和内联事件替换为 DOM API；不会自动改写或发布旧版本。发布接口也按当前规则重新验证，不能绕过前端检查。

后端执行 `node --check -` **只解析** JavaScript，拒绝窄屏根布局、常见网络/导航、持久存储、表单、内联事件和 HTML 注入 API。前端 iframe 只有 `allow-scripts`，无同源权限，CSP 限制外部连接与资源。宽屏预览改变真实视口，不做画面缩放。

此版本尚无自动浏览器交互验收或真实 API 基准；验证报告记录 `browser_tests: not_run`。静态规则不能证明混淆代码安全，iframe 也没有可靠 CPU/内存配额，无限循环仍可能拖慢标签页。包含敏感快照时先审查源码再预览；不要把当前机制扩展成任意服务端代码执行。

自动化验证：

```powershell
uv run python -m unittest discover -s tests -p "test_*.py"
```

前端仓库运行 `node --experimental-strip-types --test src/lib/*.test.ts`、`npx tsc --noEmit`、`npm run build`。测试覆盖真实框架循环、验证修复、用户隔离、恢复、预算、取消/删除竞态、私人 checkpoint 清理和聊天源码隔离；外部模型/网络调用使用 mock。
